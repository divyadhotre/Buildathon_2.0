# Contributing

1. Pull the latest `main`.
2. Create your assigned feature branch.
3. Keep changes inside your owned module when possible.
4. Run the app or relevant tests before pushing.
5. Open a Pull Request into `main`.
6. Do not commit `.env`, secrets, real invoices or private data.

## Branch ownership
- `feature/frontend`: Member 1
- `feature/ocr-verification`: Member 2
- `feature/backend-database`: Member 3
- `feature/genai-testing`: Member 4

## Commit examples
- `feat: add invoice review dashboard`
- `feat: add OCR extraction service`
- `feat: persist document versions`
- `test: add verification rule cases`
